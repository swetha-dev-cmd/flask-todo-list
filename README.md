# Flask To-Do List

A simple and clean To-Do List web application built with **Python Flask** and **HTML/CSS**.

## Features

- User Registration & Login
- Add, Complete, and Delete Tasks
- Each user has their own private tasks
- Clean and modern UI
- Indian date & time format

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Werkzeug (for password hashing)
